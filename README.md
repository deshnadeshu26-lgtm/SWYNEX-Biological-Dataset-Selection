# SWYNEX – Biological Dataset Selection

## Task 1: Biological Dataset Selection

### 1. Dataset Name

**GSE10072 – Gene expression signature of cigarette smoking and its role in lung adenocarcinoma development and survival**

### 2. Source

**NCBI Gene Expression Omnibus (GEO)**

Dataset Accession: **GSE10072**

Dataset URL:  
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE10072

### 3. Organism

**Homo sapiens (Human)**

### 4. Dataset Type

This is a **gene expression dataset** generated using microarray technology.

### 5. Dataset Size

The final analysis contains **107 expression values**, representing:

- 58 tumor tissue samples
- 49 non-tumor tissue samples

The samples include tissues from never smokers, former smokers, and current smokers.

### 6. Research Question

**How does cigarette smoking affect gene-expression patterns in lung tissue and lung adenocarcinoma?**

### 7. Why I Selected This Dataset

I selected this dataset because it is publicly available through the NCBI GEO repository and is useful for learning how biological and genomic datasets are organized.

It provides an opportunity to understand gene expression data and how biological information can be studied using computational methods.

### 8. Key Learning

From this task, I learned how to:

- Find a public biological dataset
- Identify the dataset accession number
- Understand the organism and dataset type
- Identify the number of samples
- Formulate a research question from biological data

### 9. Repository

**NCBI Gene Expression Omnibus (GEO)**

GEO is a public repository containing biological and gene expression datasets that can be used for research and learning.
